Important Google Sign-In setup
------------------------------
The Google 403 message "The given origin is not allowed for the given
client ID" cannot be fixed by JavaScript alone. In Google Cloud Console,
open Google Auth Platform > Clients > your Web OAuth client and add the
exact origin you use to open the frontend under Authorized JavaScript
origins. Examples:
  https://sathwik10126.github.io
  http://127.0.0.1:5500
  http://localhost:5500

Origins do not include a path such as /EduLink/ or /index.html.
The Client ID in config.js and backend/.env must match your Google client.

Windows setup
-------------
1. Install/start Docker Desktop.
2. Open a PowerShell terminal in the extracted EduLink-main folder:
     docker compose up -d postgres
3. Open a second terminal:
     cd backend
     Copy-Item .env.example .env
     python -m venv .venv
     .\.venv\Scripts\Activate.ps1
     python -m pip install --upgrade pip
     pip install -r requirements.txt
4. Open backend/.env and replace SECRET_KEY with a newly generated value:
     python -c "import secrets; print(secrets.token_urlsafe(48))"
   Put the generated value after SECRET_KEY= in backend/.env.
   Ensure DATABASE_URL password matches POSTGRES_PASSWORD in
   docker-compose.yml. The supplied development default is change-me.
5. Start FastAPI from the backend folder:
     python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
6. Open http://127.0.0.1:8000/health. Expected:
     {"status":"healthy"}
7. Open the project root index.html with VS Code Live Server.
   config.js is set to http://127.0.0.1:8000.

Important hosting limitation
-----------------------------
GitHub Pages only hosts the static frontend. This project's config.js
points to a backend on 127.0.0.1:8000, so API features work only in a
browser on the same computer while its FastAPI server and PostgreSQL
are running. Other visitors' 127.0.0.1 refers to their own computer.
This is not a public multi-user backend deployment.
